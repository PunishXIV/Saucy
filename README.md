Automates certain Gold Saucer mini-games.

#### Currently supports

- Triple Triad
- Mini Cactpot
- Jumbo Cactpot
- Cuff-a-Cur
- Out on a Limb
- Air Force One
- GATE: The Slice is Right
- GATE: Any Way the Wind Blows

Tracks stats for lifetime, sessions, hourly MGP and more!
