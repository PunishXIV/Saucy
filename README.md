# Saucy

When working for MGP is too much effort.

Automates Gold Saucer mini-games and tracks your stats.

</div>
<!-- Repository Header End -->

## Install

1. Dalamud → **Settings** → **Experimental**
2. Add this repo: `https://love.puni.sh/ment.json`
3. Install **Saucy** from the plugin installer

## Games

Triple Triad · Mini Cactpot · Jumbo Cactpot · Cuff-a-Cur · Out on a Limb · Air Force One · GATE (Slice is Right / Wind Blows)

Open Saucy in-game, pick a game, turn it on. If something needs another plugin, Saucy will tell you.
